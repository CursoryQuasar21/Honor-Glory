# ⚔️ Honor & Glory

**Honor & Glory** es una aplicación web de combate estratégico multijugador construida en PHP. Los jugadores pueden registrarse, crear o unirse a salas y combatir entre sí utilizando diferentes clases de personajes. El sistema incluye inteligencia artificial (IA), variedad de héroes y un entorno modular con interfaz visual y recursos gráficos personalizados.

---

## 🧩 Características principales

- 🧑‍🤝‍🧑 Registro e inicio de sesión de usuarios
- 🛡️ Clases jugables: Héroe, Asesino, Pesado, Vanguardia
- 🧠 Soporte para jugadores IA y humanos
- 🏰 Sistema de creación, búsqueda y entrada a salas de combate
- 🖼️ Interfaz personalizada con recursos visuales (imágenes, GIFs)
- 🔁 Arquitectura modular basada en componentes PHP

## ⚙️ Instalación y ejecución local

1. Clona este repositorio:
   ```bash
   git clone https://github.com/CursoryQuasar21/Honor-Glory.git
   ```

2. Coloca los archivos en el directorio raíz de tu servidor web (por ejemplo, `htdocs` si usas XAMPP).

3. Abre tu navegador en:
   ```
   http://localhost/Honor-Glory/index2.php
   ```

4. Asegúrate de tener habilitado el uso de sesiones en PHP y soporte para rutas relativas.
